# Replit Agent — Platform Repository

This repository contains platform infrastructure capabilities for Project Zero.

Before changing code:
1. Read the master repository's Replit Agent guardrails and approved source documents.
2. Confirm the relevant platform specification, version, dependencies, and implementation-stage approval.
3. Identify the interface contract with the protected engine core and experience layer.
4. Propose changes and tests before implementation.
5. Do not invent APIs, permissions, data models, or deployment topology when source requirements are missing.

Never implement gameplay-specific rules here merely because they are used by multiple sample worlds. Keep platform services generic and contract-driven.

No feature implementation is authorized by the existence of this scaffold.
